# Changelog

## [1.0.0] - 2026-10-03

### Added

- First release of the ShamCash PHP SDK.
- `createBill`, `getBill`, `refundBill`, `listTransactions`, and `eachTransaction`.
- `parseWebhook` for the encrypted ShamCash callback.
- Optional client defaults for `callbackUrl` and `redirectUrl`, with a per-bill override.
