# Security

Report a vulnerability in this SDK privately through [GitHub security advisories](https://github.com/OkToCode-L-L-C/Sham-Cash-PHP-SDK/security/advisories/new).

Do not open a public issue that contains a `secretKey`, an `encData` token, or a decrypted payload.

The `secretKey` authorizes your ShamCash account. Store it in server-side configuration. If it leaks, contact ShamCash support so they can revoke it and issue a new one.
